# Oja

Shelf for Nigerian browser games. Open in your browser, no download.

Live preview: https://htmlpreview.github.io/?https://github.com/temisangerrard/oja/blob/main/index.html

GitHub Pages (after one toggle): https://temisangerrard.github.io/oja/

Settings → Pages → Deploy from branch → `main` / root → Save.

Games open on the creator's site. Oja does not host them.
